load_netflix_data <- function(){

  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)

  data_dir <- path("data", "mp01")

  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings = FALSE, recurse = TRUE)
  }

  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )

  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }

    return(local)
  }

  NETFLIX_URLS |>
    map(read_html) |>
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |>
    map_chr(html_attr, "href") |>
    enframe("period", "url") |>
    mutate(
      path = path(data_dir, paste0(period, ".xlsx")),
      path = map2(url, path, download_if_needed),
      data = map(path, read_excel, skip = 3, na = "*"),
      data = map(data, \(x) x |>
        mutate(`Release Date` = as.Date(`Release Date`)))
    ) |>
    unnest(data) |>
    select(-url, -path) |>
    mutate(
      year = str_sub(period, 1, 4),
      half = str_sub(period, start = 6),
      period_start = make_date(
        year,
        if_else(half == 1, 1, 7),
        1
      ),
      period_end = make_date(
        year,
        if_else(half == 1, 6, 12),
        if_else(half == 1, 30, 31)
      )
    ) |>
    filter(!is.na(`Hours Viewed`)) |>
    mutate(
      live_event = !is.na(Runtime) &
        str_detect(Runtime, "\\d+:\\d+\\*"),
      clean_time = str_remove(Runtime, fixed("*")),
      Runtime = 60 * hour(hm(clean_time)) +
        minute(hm(clean_time))
    ) |>
    select(-clean_time) |>
    mutate(
      Runtime = coalesce(
        Runtime,
        mean(Runtime, na.rm = TRUE)
      ),
      .by = Title,
      Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
      Title = str_remove(Title, " // .*"),
      Title = str_remove(Title, "[^[:ascii:]].*"),
      Title = str_trim(Title)
    ) |>
    filter_out(Title == "") |>
    select(
      year,
      period,
      period_start,
      period_end,
      Title,
      -half,
      Runtime,
      Views,
      `Hours Viewed`,
      `Release Date`,
      `Available Globally?`,
      live_event
    )
}

NETFLIX_DATA <- load_netflix_data()

Task 7: Strategy Memo

To: Netflix Leadership
From: Alex Jacob
Re: Content Strategy for 2027 and Beyond

For 2027 and beyond, Netflix should prioritize high-performing scripted series and globally available content, while being more selective with live programming.

Recommendation 1: Invest in global scripted series and proven franchises

Global availability is one of the strongest signals in the data. Only 35.09% of the catalog is available globally, yet those titles generate 51.92% of total viewing hours. Wider global availability appears to be associated with disproportionately high engagement. When a title can reach every market at once, it has a much better chance of becoming a hit. Netflix should make global release the standard for its biggest titles.

The format also matters. Shows accounted for a larger share of viewing than movies in every reporting period. Since 2023H2, shows have made up more than 96% of total viewing hours, and even in 2023H1, their lowest period, they still accounted for 70.52%. Recurring series build audiences over time. Viewers who finish one season come back for the next, which creates repeat engagement that a single movie usually cannot match.

The strongest performers support this. Squid Game, Stranger Things, Bridgerton and Wednesday keep appearing among the top titles. Squid Game: Season 2 led two reporting periods in a row, and Bridgerton was the top title in two separate periods with different seasons. Netflix should keep investing in these established franchises because they reliably bring audiences back. It should also keep developing new franchises so it is not overly dependent on a handful of series that will eventually end.

Recommendation 2: Be selective with live content and focus on quality over quantity

Live programming has not performed at the same level as scripted content. Live events averaged about 3,560,000 viewing hours, compared with about 8,289,547 for pre-taped content. The gap is even bigger at the top end. The top-10% threshold was 6,500,000 hours for live events versus 20,000,000 for pre-taped content. This means live events rarely reach the level of Netflix’s biggest scripted hits. Live content can still be useful for major moments and for creating buzz. However, Netflix should choose it selectively and not treat it as a major replacement for scripted programming.

The catalog data adds another lesson. From 2023H2 onward, the catalog expanded steadily, growing from 6,574 titles to 8,163 by 2026H1, while total runtime also increased over the same period. Simply adding more content is not enough to grow engagement. The titles that drive viewing are the ones with broad global appeal and strong repeat viewing. Netflix should be more selective about what it adds and put its money behind fewer, stronger titles instead of chasing a bigger library.

Conclusion

Netflix’s 2027+ strategy should center on global scripted series and continued investment in proven franchises, while still developing new ones. Live events should be treated as selective experiments rather than a core part of the lineup. Above all, Netflix should focus on quality over raw catalog expansion. The data shows that a smaller number of strong, globally available series drive far more engagement than volume alone.
